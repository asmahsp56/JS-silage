# JS Silage & Wanda Factory

Official website for **JS Silage & Wanda Factory**, Hasilpur.

## About

JS Silage & Wanda Factory provides quality **silage, wanda, and livestock feed products** for farmers and livestock owners in Hasilpur and surrounding areas.

This website provides customers with information about the business, products, services, and contact details.

## Features

* 🏭 Business information
* 🌾 Silage and wanda products
* 📋 Product details
* 📞 Contact information
* 📱 Responsive design for mobile, tablet, and desktop
* ⚡ Fast and lightweight website
* 🌐 Ready for deployment with GitHub Pages

## Technologies Used

* HTML5
* CSS3
* JavaScript
